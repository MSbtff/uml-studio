# UML Studio DDL to Mermaid v0.1.0

First public release of `uml-studio-ddl-to-mermaid`, a Node.js library for converting SQL DDL into an ERD model and Mermaid `erDiagram` source.

## Highlights

- Parse common PostgreSQL, MySQL, and SQLite `CREATE TABLE` statements.
- Generate a JSON-serializable UML Studio ERD model and Mermaid source from the same SQL input. The converter reports warnings for unresolved foreign keys.
- Use `ddlToMermaid` from ESM or CommonJS. The package includes TypeScript declarations, sample SQL, and a runnable conversion example.

## Installation

Requires Node.js 24 or later. The package has no runtime dependencies.

```sh
npm install uml-studio-ddl-to-mermaid@0.1.0
```
