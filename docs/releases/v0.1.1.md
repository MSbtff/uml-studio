# UML Studio DDL to Mermaid v0.1.1

This patch updates the documentation for `uml-studio-ddl-to-mermaid`.

## Changes

- Publish the package README in English, including SQL support, ESM and CommonJS usage, and TypeScript types.
- Show how to run the bundled SQL example and convert your own schema into a Mermaid file.
- Put the npm installation steps first in the repository quick start and give the browser editor its own setup section.

## Install and run

Use Node.js 24 or later. Run these commands from your Node.js project to install the package and generate `schema.mmd` from the bundled sample.

```sh
npm install uml-studio-ddl-to-mermaid@0.1.1
node node_modules/uml-studio-ddl-to-mermaid/examples/convert.mjs > schema.mmd
```

[View `uml-studio-ddl-to-mermaid@0.1.1` on npm](https://www.npmjs.com/package/uml-studio-ddl-to-mermaid/v/0.1.1)
